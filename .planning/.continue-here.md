## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Desktop-first responsive `order` | Wrote DOM order to match the desktop visual layout, then bolted on `order-first lg:order-none` to reflow mobile. Created a real mismatch: sighted keyboard/screen-reader users tabbing on mobile hit controls in an order that didn't match what they saw on screen. | advisory | Write DOM order mobile-first (natural stacking order = correct mobile order, no override needed) and reflow for wider viewports with `lg:order-*` instead — the reverse of what was originally shipped. Already fixed in `neo-draw-ai-scaffold/src/app/page.tsx`. |
| Fixed-breakpoint font-size on unbreakable single-word content | `GuessReveal`'s single guess word used `text-4xl sm:text-5xl` inside a box hard-capped at `max-w-md`. A single word (no spaces) can't wrap, so at in-between window widths it silently overflowed the box with **no scrollbar warning** — user had to zoom the whole page to 90% to see the rest of the word. | advisory | For single-token dynamic content (labels, tags, one guessed word), use `clamp()`-based fluid font-size instead of fixed Tailwind breakpoints, and don't assume a parent `max-width` alone prevents overflow — a block child with unbreakable content can and will overflow past it visibly. Already fixed. |

**Severity values:** `blocking` — resuming agent must pass understanding check before proceeding. `advisory` — important context, does not gate resumption.
